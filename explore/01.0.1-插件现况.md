## 4. 已知限制（如实）

1. **不能给模型省 token**：preset 注册的 own 工具对 `tools.restrict` 豁免（实测 restrictable 仅 6 个全局工具），白名单是执行期拒止（guard），schema 仍发给模型；省 token 的官方途径 = 会话级 agent 预设（preset-minimal 等）。
2. 子代理模型路由策略只写**全新顶层会话**（DSH 设计）；旧会话只能选父路由。
3. 白名单目录冷启动靠「静态兜底 33 个 + 持久化历史目录」；首次无活 agent 时可能与实际有差异（执法不依赖目录）。
4. 问答模式幻觉路径（`.dsh/last_session.log`）已通过去掉本地文件类工具缓解，但模型幻觉本身无法由插件根治。
