# 01.0.3 插件详细介绍（dsh-dashboard）

> 2026-11-17 ｜ v3 独立架构全貌 ｜ 依据：源码 + 0.2.2 asar 核对 + 全链路实测

## 1. 定位与形态

DSH 插件（Cordis bundle），双模式会话控制台：

- **① ⚙ 小齿轮**：DSH 窗口右下角 34px 白齿轮（`shell.overlay` 槽位，可拖、位置记忆 `localStorage:dshdash:dot-pos`）。单击弹窗：打开外窗 / 关闭控制台（红）/ 提示行 + **会话下拉**（最近 10 条，`GET /recent`）+ 说明；**点弹窗外任意处收起**。
- **② 外窗**：透明置顶桌宠窗（独立 Electron helper 进程），完整控制面。
- 总开关 OFF：两模式全消失 + 杀 helper；唯一开启入口 = 设置 → 控制台设置（`settings.section` 槽位）。

## 2. 数据面四支柱（全部 DSH 原生，零外部依赖）

| 能力 | 机制 | 说明 |
|---|---|---|
| 会话列表 | `ctx.sessionQuery.listSessions()` + `readTitleSnapshots(ids)` | DSH 会话 id 唯一 → 同首消息多会话**结构性区分**；标题与工作区一致、重命名 ≤5s 同步 |
| 工具白名单 | `agent.ctx.tools.restrict({allow})`（全局工具）+ `agent.ctx.tools.guard(exec.name)`（全部工具执行期拒止） | agent 解析：`agent/created` 跟踪 + **`ctx.get('agents').get(sid)` 兜底**（覆盖插件加载前已存在的 agent）+ 启动清扫 `agents.list()` |
| token 预算 | `agent/pre-step` → `ctx.tokenMeter.measure(session).totalTokens` ≥ 预算 → `ctx.compaction.compactNow(agent)` | 预算范围 1024~1M（覆盖 Qwen 32K 与 DeepSeek 1M）；用量实时显示（`/api/usage`，sessions 服务兜底无 agent 的 live 会话） |
| 清空上下文 | `ctx.compaction.compactNow`（软取 `ctx.get('compaction')`） | 仅活动会话；冷会话提示「未挂载」；web 组合默认禁用 compaction-basic，已由 bundle patch 启用（用户确认，注意自动压缩全局生效） |

## 3. 进程与网络架构

```
DSH 宿主（插件 lib/index.js）
 ├─ webServer 路由 /dsh-dashboard/*        ← DSH 页面（同源 fetch）
 │   顶层（无 token）：state / open / set-master / close-window / select / recent
 │   api/*（token）：sessions / tools / usage / budget / allow / clear / defaults / select
 └─ spawn helper（删除 ELECTRON_RUN_AS_NODE！env: DSH_DASH_HOST_PID/TOKEN/PORT/URL/
      STATE_DIR/LOG/HOST_ORIGIN）
helper（Electron 44.7.0，私有目录 ~/.dsh/dsh-dashboard/electron/，SHA256 校验）
 ├─ HTTP 127.0.0.1:8792（占用自动 +1×10；stdout DASHBOARD_PORT 握手）
 │   /__health、/__ctl（token；show/close/quit）、/standalone.html（no-store + 缓存穿透）
 │   /api/* → 反代 HOST_ORIGIN + /dsh-dashboard/api/*（带 token；**透传全部响应头含
 │            Content-Encoding**——丢它会导致 gzip 体被当明文，曾致「数据源不可达」假死）
 ├─ BrowserWindow：transparent/frame:false/skipTaskbar/hasShadow:false/
 │   roundedCorners:false/alwaysOnTop('screen-saver')/window-state 记忆；✕ 只关窗留进程
 └─ 看门狗：每 3s kill(DSH_DASH_HOST_PID,0)，ESRCH → 自尽
```

## 4. 状态文件（~/.dsh/dsh-dashboard/）

| 文件 | 内容 |
|---|---|
| master.json | 总开关 `{"on":bool}` |
| console.json | 选中会话 selectedSessionId、默认（budget/allow）、每会话（budget/allow）、工具目录缓存 toolCatalog |

## 5. 外窗 UI（standalone.html，vanilla 零依赖）

- 顶栏（拖拽区）状态点/⚙/✕；提示条；**常驻选中区**（标题+状态+白名单摘要）；会话列表**内部滚动**（活动/冷标记）；底部详情（token 预算+用量 / 工具白名单折叠 / 清空二次确认）；页脚（数据源/5s 轮询/更新时间）。
- 工具白名单**列表式**：左工具名（等宽字体）右 2~6 字中文说明（TOOL_DESC 词典 41 项，未收录留空）；选中行高亮；max-height 240 内部滚动。
- **场景预设按钮**（会话区+默认区各一组）：
  - 问答 = **排除式**（除 `schedule_*`、`team_task_*` 外全给，动态跟随目录）
  - 编程 = 固定 22 工具集；全选 = 目录全量
- 目录多源并集：全局 view ∪ 全部活 agent 作用域 view ∪ 持久化历史目录 ∪ 静态兜底 33 个；防竞态（单入口 refreshTools + 代际守卫 + pending 重拉 + 选中校验）。

## 7. 已知限制

1. own 注册工具对 restrict 豁免 → 白名单**不能减模型 schema/token**（guard 只拒执行）；省 token 需会话级 agent 预设（preset-minimal）。
2. 子代理模型路由策略只写全新顶层会话（DSH 设计）。
3. 默认白名单只影响新 agent，不回溯已存在 agent。
4. 白名单目录冷启动（无活 agent）靠静态兜底，可能与真实目录有小差异（执法不依赖目录）。
