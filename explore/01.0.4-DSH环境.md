  - `session-log-deepseek` → disabled
- 插件管理：`plugin_manager`（install_bundle 链接安装 / set_plugin / remove_bundle）；**手工改 patch 层需重启 DSH 才装载**；`.volatile()` 字段热更新但 patch 层本身不热。

## 3. 组合与槽位关键事实（0.2.2）

- 行 id：`include:` 前缀是组合命名空间，patch 用**行 id**（如 `llm-pi-ai`、`subagent-model-selection-settings`、`compaction-basic`）定位；
- 服务名：`webServer`（register kind: exact/prefix；port/getOrigin）、`sessionQuery`、`tools`（view/restrict/guard，exec={callId,name,arguments,agent,…}）、`compaction`、`tokenMeter`（measure(session).totalTokens）、`agents`（get/list）、`sessions`（get）、`dshHomePath`、`workspaceRegistry`；
- 客户端：`window.__ModuleLoader__.load({id,factory})`；槽位 `shell.overlay`、`settings.section`；主题 token `--dsw-alias-*`；
- 事件：`agent/created`（payload {agent,source}）、`agent/disposed`、`agent/pre-step`（瀑布，必须 return next()）。

## 4. 工具架构（决定白名单能力边界）

- 工具分两类：**全局注册**（本组合仅 6 个：load_workspace_dependencies、team_task_*、working_directory）与 **agent 作用域（own）注册**（preset 注册的 read/write/bash/… 约 35 个）；
- `tools.restrict({allow})` 只接受 `restrictableNames`（= 全局 6 个），**own 工具豁免**；`tools.guard(fn)` 按 `exec.name` 拒止**全部**工具（执行期，不减 schema）；
- agent-loop 请求信封被 `Object.freeze`，llm/stream 瀑布**无法改写**（注入不了会话标识/头）；pi-ai 请求体白名单、compat 门 `sendSessionAffinityHeaders: withhold`——DSH 0.2.2 请求侧无会话标识通道（本会话抓包实证）。

## 5. 关键机制与坑（实证清单）

1. `ELECTRON_RUN_AS_NODE=1` 由 DSH 运行时注入——spawn 子进程前必须 delete；
2. DSH 页面协议 `dsh-app://`——外窗 URL 必须宿主自拼，禁止 `location.origin`；
3. 反代必须透传 `Content-Encoding`（丢 gzip 头 = 页面把压缩体当明文 → 假性「数据源不可达」）；
4. 半透明图层会使 Chromium 关闭亚像素抗锯齿（文字模糊）→ 卡片用不透明背景；
5. compaction-basic 在 web 组合**默认禁用**（启用 = 全局自动压缩），/compact 命令同被覆盖；由插件 patch 启用；
6. 子代理模型选择策略（subagent/model-selection-policy）**只写全新顶层会话**；旧会话仅父路由；
7. `sessionQuery` 折叠 281+ 会话标题冷读 ~5-10s → 需缓存（插件 4s 负载缓存）+ 反代超时放宽（30s）；
8. 冷启动无活 agent 时工具目录只剩 6 个全局——目录需多源并集 + 持久化 + 静态兜底；
9. 手工 profile 编辑的生效路径：patch 层重启装载；行开关（set_plugin）即时应用；
10. AppTranslocation 每次启动路径变化——诊断脚本里的 asar 路径要随运行时上下文更新。

## 6. 常用操作速查

| 操作 | 命令/方式 |
|---|---|
| 插件重装/刷新 patch | `plugin_manager install_bundle`（已装需先 remove_bundle） |
| 行开关（宿主 lib 改动生效） | `set_plugin include:dsh-dashboard false→true` |
| 重启代理 | `ssh071 'export XDG_RUNTIME_DIR=/run/user/$(id -u); systemctl --user restart llama-proxy'` |
| 插件状态 | `curl http://127.0.0.1:<GUI端口>/dsh-dashboard/state` |
| 外窗数据面 | `curl http://127.0.0.1:8792/api/sessions` |
